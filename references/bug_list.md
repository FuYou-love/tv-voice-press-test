# 缺陷清单（Bug List）

> 新增缺陷时按下方模板追加，编号顺延（BUG002、BUG003…）。

## BUG001
- **标题**：高环境噪音场景下，语音唤醒失败
- **所属模块**：语音唤醒模块
- **关联用例**：wakeup_noisy.wav（自动扫描，预期"唤醒成功"）
- **复现步骤**：
  1. 播放高背景噪声的唤醒音频
  2. 抓取电视 VoiceService 语音服务日志
- **实际结果**：日志输出 `wakeup_fail`，无法唤醒设备
- **预期结果**：可以正常唤醒
- **严重级别**：一般
- **日志片段**：`I/VoiceService: wakeup_fail`
- **建议修复方案**：优化前端降噪算法，增强噪声环境下唤醒识别能力
